What is the most useful thing you can do with a transform?

The most useful thing I can do with transform is smoothly move, resize, and rotate elements visually without disturbing the layout of surrounding elements on the page.

What is the difference between a transform and a transition?

A transform changes an element's physical shape, size, and position, whereas a transition controls how gradually any CSS property changes from one state to another over time.
